# Fundación Choyinko — Style Reference

## 1. Concepto visual

Theme: Nature-inspired institutional editorial
Brand: Fundación Choyinko
Visual direction: Agua, territorio, biodiversidad, cultura mapuche, comunidad y sostenibilidad.

Diseña un sitio web institucional moderno, elegante y cercano para Fundación Choyinko. La identidad debe transmitir conexión con la naturaleza, protección del agua, respeto por el territorio y compromiso comunitario.

Utiliza como referencia visual el estilo "Limón — Style", conservando sus principios de diseño editorial, tipografía con tracking positivo, jerarquía visual marcada, superficies planas, navegación limpia y uso intencional del espacio en blanco.

No reproduzcas literalmente la estética de un restaurante ni sus fotografías gastronómicas, colores originales o elementos comerciales. Reinterpreta su lenguaje visual para una fundación ambiental y cultural.

La identidad debe sentirse orgánica, sobria, contemporánea y con raíces territoriales, evitando tanto una estética corporativa genérica como una representación folclórica superficial de la cultura mapuche.

## 2. Paleta oficial de colores

Utiliza exclusivamente los siguientes diez colores como paleta cromática principal. Se permiten transparencias derivadas de estos colores y el uso de imágenes reales. No introduzcas colores de marca adicionales.

| Color | Token CSS | Función recomendada |
|---|---|---|
| #3B4B1C | `--color-forest-olive` | Verde bosque principal, encabezados, navegación y fondos institucionales oscuros |
| #F3F5EF | `--color-soft-white` | Fondo principal claro, superficies de contenido y áreas de lectura |
| #207697 | `--color-river-blue` | Azul agua, enlaces, elementos gráficos y secciones relacionadas con el agua |
| #BF8620 | `--color-earth-gold` | Acentos cálidos, llamadas a la acción y detalles destacados |
| #0A5470 | `--color-deep-water` | Fondos azules oscuros, botones secundarios y secciones de alto contraste |
| #7F8952 | `--color-sage-olive` | Fondos secundarios, etiquetas y detalles botánicos |
| #77592F | `--color-earth-brown` | Detalles de tierra, madera, naturaleza y elementos gráficos |
| #D1C493 | `--color-sand-beige` | Superficies cálidas, fondos alternativos y separadores destacados |
| #8FB5B5 | `--color-water-mist` | Acentos acuáticos suaves, fondos informativos y detalles decorativos |
| #301907 | `--color-deep-earth` | Texto sobre fondos claros, fondos oscuros alternativos y footer |

### Distribución cromática

La paleta debe utilizarse con jerarquía y moderación. No distribuyas los diez colores de manera uniforme por toda la interfaz.

- **60 %** — Superficies claras: `#F3F5EF`, para lectura, contenido institucional y descanso visual.
- **20 %** — Tonos verdes: `#3B4B1C` y `#7F8952`, para identidad, naturaleza y jerarquía.
- **10 %** — Tonos azules: `#207697`, `#0A5470` y `#8FB5B5`, para representar el agua y los elementos acuáticos.
- **10 %** — Tonos tierra: `#BF8620`, `#77592F`, `#D1C493` y `#301907`, distribuidos según la función de cada componente.

Estas proporciones son una guía visual, no una regla matemática estricta. El color `#301907` puede utilizarse en grandes superficies oscuras, pero debe alternarse con superficies claras para evitar que el sitio resulte demasiado pesado.

### Reglas de contraste

- Utiliza `#F3F5EF` como fondo claro principal.
- Utiliza `#3B4B1C` como color institucional verde dominante.
- Utiliza `#0A5470` para superficies acuáticas oscuras.
- Utiliza `#301907` principalmente para texto oscuro y fondos de contraste.
- Utiliza `#207697` para enlaces y elementos interactivos cuando el contraste sea suficiente.
- Reserva `#BF8620` para acentos y llamadas a la acción.
- Utiliza `#8FB5B5` y `#D1C493` preferentemente como fondos suaves, no como texto pequeño sobre blanco.
- Comprueba el contraste WCAG AA: 4,5:1 para texto normal y 3:1 para texto grande y componentes gráficos relevantes.
- No utilices combinaciones de bajo contraste solo porque los colores pertenecen a la marca.

## 3. Tipografía

### Familia tipográfica principal

Utiliza **Outfit** como tipografía principal, con alternativa a **DM Sans**, **Plus Jakarta Sans** o fuentes del sistema.

La tipografía debe mantener la sensación editorial del estilo de referencia, pero transmitir confianza institucional, legibilidad y cercanía.

Pesos: 300, 400, 500, 600 y 700.

- Texto de navegación: 14–16 px.
- Texto de cuerpo: 16–19 px.
- Subtítulos: 22–28 px.
- Encabezados de sección: 30–40 px.
- Encabezados principales: 46–68 px en escritorio.
- Encabezados destacados: hasta 75 px cuando el contenido lo justifique.
- Interlineado del cuerpo: 1,5–1,7.
- Interlineado de encabezados: 1,0–1,2.
- Tracking de títulos grandes: 0,02–0,05 em.
- Tracking de texto normal: 0–0,02 em.

No fuerces el espaciado entre letras en párrafos largos. La legibilidad debe prevalecer sobre el efecto decorativo.

### Jerarquía tipográfica

Utiliza títulos grandes para mensajes institucionales, títulos medianos para secciones y texto de cuerpo cómodo para explicar los proyectos, objetivos, actividades y formas de colaboración de la fundación.

La palabra **CHOYINKO** puede utilizar una composición tipográfica distintiva, siempre que se respete el logotipo oficial cuando esté disponible.

## 4. Sistema de diseño

- Unidad base de espaciado: 4 px.
- Ancho máximo del contenido: 1200 px.
- Separación entre secciones: 64–96 px en escritorio.
- Padding de tarjetas: 24–32 px.
- Separación entre elementos: 16–24 px.
- Radio de botones: 2–4 px.
- Radio de tarjetas: 0–4 px.
- Radio de imágenes: 0–4 px.
- Bordes: finos y discretos.
- Sombras: mínimas o inexistentes.

Conserva la estética plana y editorial del estilo de referencia. La jerarquía debe surgir principalmente del tamaño, el espacio, la tipografía, la fotografía y el contraste cromático.

No conviertas todos los componentes en tarjetas redondeadas ni utilices sombras excesivas, gradientes decorativos o efectos visuales innecesarios.

## 5. Navegación principal

Crea una barra de navegación institucional, limpia y adaptable.

### Escritorio

- Logotipo de Fundación Choyinko a la izquierda.
- Enlaces de navegación alineados a la derecha.
- Fondo claro `#F3F5EF` o verde `#3B4B1C`, dependiendo de la composición de la página.
- Texto oscuro sobre fondos claros y texto claro sobre fondos oscuros.
- Estado activo claramente identificable.
- Botón destacado para apoyar, participar o contactar, según los objetivos reales de la fundación.

### Móvil

- Menú compacto con botón accesible.
- Logotipo visible y correctamente proporcionado.
- Navegación por teclado y soporte para lectores de pantalla.
- Sin desbordamientos horizontales.

No inventes enlaces a secciones, servicios o programas que no estén definidos en los contenidos del proyecto.

## 6. Hero principal

Diseña una sección inicial de alto impacto editorial.

Debe combinar:

- Un título institucional claro y memorable.
- Una breve descripción de la misión de la fundación, basada en información real.
- Una imagen auténtica y relevante del territorio, agua, biodiversidad o comunidad.
- Una llamada a la acción principal y, si corresponde, otra secundaria.
- Un diseño adaptable a escritorio, tablet y móvil.

### Tratamiento visual

Alterna fondos claros `#F3F5EF` con bloques verdes `#3B4B1C` o azules `#0A5470`.

Puedes utilizar titulares grandes con tracking moderado, fotografías amplias y composiciones asimétricas inspiradas en el diseño editorial.

Utiliza `#BF8620` como acento puntual, no como un equivalente permanente del amarillo brillante de la referencia original.

Evita superponer texto sobre fotografías si no puedes garantizar una legibilidad adecuada.

## 7. Secciones de contenido

Utiliza una combinación equilibrada de superficies claras, bloques de color y fotografía.

### Identidad y misión

Presenta la misión, visión y valores con títulos expresivos, párrafos legibles y suficiente espacio en blanco.

### Proyectos e iniciativas

Utiliza una cuadrícula editorial con fotografías de proporciones coherentes, títulos breves, descripciones y enlaces para conocer cada proyecto.

Las tarjetas deben tener una estructura visual sencilla, sin bordes pesados ni sombras innecesarias.

### Territorio y naturaleza

Utiliza fotografías reales de ríos, vertientes, bosques, flora y paisajes pertinentes para la actividad de la fundación.

Prioriza imágenes locales y autorizadas. No presentes imágenes genéricas como si documentaran actividades reales de la organización.

### Cultura y comunidad

Representa a las personas, las comunidades y el patrimonio cultural con respeto, contexto y autenticidad.

No inventes símbolos ceremoniales ni utilices elementos culturales mapuche como decoración arbitraria. Emplea el logotipo y los recursos gráficos autorizados por la fundación.

### Participación y contacto

Destaca las formas reales de colaborar, participar, consultar o contactar a la organización.

Los botones deben tener etiquetas descriptivas y conducir a acciones funcionales.

## 8. Botones y enlaces

### Botón principal

- Fondo: `#3B4B1C` o `#0A5470`.
- Texto: `#F3F5EF`.
- Peso tipográfico: 600.
- Padding: 12–16 px vertical y 18–24 px horizontal.
- Radio: 2–4 px.
- Sin sombras intensas.

### Botón de acento

- Fondo: `#BF8620`.
- Texto: `#301907`, siempre que se compruebe el contraste.
- Uso: acciones prioritarias y puntuales.

### Botón secundario

- Fondo transparente.
- Borde de 1 px en el color de texto.
- Texto heredado de la superficie.
- Cambio visible de fondo, borde o color al interactuar.

### Enlaces de texto

Utiliza `#207697` sobre fondos claros cuando el contraste cumpla los requisitos de accesibilidad. En fondos oscuros, selecciona un color claro de la paleta que cumpla el contraste necesario.

Todos los botones, enlaces y controles deben tener estados visibles de hover, focus, active y disabled cuando corresponda.

## 9. Imágenes y dirección artística

Las imágenes deben ser protagonistas visuales, con un tratamiento editorial, natural y documental.

Prioriza:

- Agua en movimiento, vertientes y cursos de agua.
- Bosques nativos y flora local.
- Canelo y otras especies pertinentes.
- Paisajes del territorio donde actúa la fundación.
- Actividades comunitarias reales.
- Proyectos ambientales y educativos documentados.

Evita:

- Fotografías gastronómicas del estilo original.
- Fotografías corporativas de stock genéricas.
- Imágenes artificiales que parezcan documentar actividades inexistentes.
- Saturación excesiva y filtros dramáticos.
- Iconografía cultural descontextualizada.

Las fotografías deben conservar una apariencia natural, con recortes coherentes y buena resolución. Añade textos alternativos descriptivos cuando sean imágenes informativas.

## 10. Iconografía y elementos gráficos

Utiliza iconos lineales, simples y consistentes.

Los elementos gráficos pueden inspirarse visualmente en flujos de agua, hojas, cauces y formas orgánicas, siempre que no compitan con el contenido ni alteren los símbolos culturales de la identidad institucional.

Utiliza el logotipo oficial de la fundación si está disponible. No reconstruyas ni modifiques el guñelve u otros elementos del logotipo sin autorización.

Los separadores, líneas y pequeños detalles pueden utilizar `#7F8952`, `#D1C493` o `#8FB5B5`, según el fondo y la función.

## 11. Footer institucional

Diseña un footer visualmente sólido, preferentemente con fondo `#301907` o `#3B4B1C` y texto `#F3F5EF`.

Incluye únicamente información confirmada:

- Logotipo.
- Breve descripción institucional.
- Enlaces de navegación.
- Datos de contacto oficiales.
- Redes sociales existentes.
- Información legal y de privacidad, si corresponde.
- Créditos y derechos de autor.

Utiliza separadores sutiles y evita saturar el pie de página.

## 12. Accesibilidad y diseño adaptable

- Diseña con enfoque mobile-first.
- Cumple WCAG 2.2 AA como objetivo de accesibilidad.
- Utiliza HTML semántico.
- Garantiza navegación completa mediante teclado.
- Mantén indicadores de foco visibles.
- No comuniques información únicamente mediante el color.
- Respeta `prefers-reduced-motion`.
- Utiliza tamaños de texto legibles.
- Evita animaciones que distraigan o dificulten el acceso al contenido.
- Optimiza las imágenes para no perjudicar la carga móvil.

## 14. Criterios de implementación

Al desarrollar el sitio:

- Conserva esta identidad visual como referencia consistente para todas las páginas.
- Reutiliza los tokens de color, tipografía, espaciado y componentes.
- No introduzcas colores ajenos a la paleta principal.
- Mantén una composición editorial, limpia y sin efectos decorativos excesivos.
- Prioriza el contenido, la accesibilidad, la velocidad y la experiencia móvil.
- Utiliza contenido real proporcionado por la fundación.
- No inventes proyectos, testimonios, integrantes, cifras ni datos de contacto.
- Comprueba el contraste de texto, botones, enlaces y estados interactivos.
- Optimiza las imágenes y evita dependencias innecesarias.
- Mantén una implementación coherente, accesible y fácil de mantener.

## 15. Resultado esperado

El resultado debe ser un sitio web institucional que combine el lenguaje editorial y minimalista del estilo de referencia con una identidad propia para Fundación Choyinko.

La interfaz debe evocar agua, naturaleza, territorio y comunidad mediante la paleta verde, azul y tierra, una tipografía contemporánea, fotografías auténticas y una jerarquía visual clara.

La prioridad es que el sitio se reconozca como Fundación Choyinko, no como una adaptación de una web gastronómica.
